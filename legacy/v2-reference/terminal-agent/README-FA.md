# عامل محلی کارتخوان 3Food POS

این برنامه برای کامپیوتر صندوق ویندوز طراحی شده است. عامل فقط از طریق HTTPS به API متصل می‌شود و درخواست‌های صف را به درایور محلی می‌دهد.

## وضعیت
- احراز هویت عامل، heartbeat، دریافت صف و ارسال نتیجه پیاده‌سازی شده است.
- معماری درایور مبتنی بر مستندات رسمی ECR نیاز دارد.
- هیچ درایور بانکی واقعی در این نسخه وجود ندارد. بدون درایور معتبر، نتیجه `unknown` ثبت می‌شود و پرداخت موفق فرض نمی‌شود.
- خروجی ویندوز در CI به‌صورت self-contained ساخته می‌شود و .NET روی کامپیوتر صندوق لازم نیست.

## راه‌اندازی
1. در تنظیمات 3Food POS یک عامل محلی بسازید و توکن یک‌بارنمایش را کپی کنید.
2. `terminal-agent.example.json` را به `terminal-agent.json` تغییر نام دهید.
3. آدرس HTTPS واقعی POS و توکن را در آن قرار دهید. این فایل را منتشر یا در Git ذخیره نکنید.
4. برنامه را اجرا کنید. وضعیت اتصال در تنظیمات POS با heartbeat به‌روزرسانی می‌شود.
5. کارتخوان فقط پس از نصب درایور رسمی و تأییدشده قابل استفاده است.

## قرارداد درایور
درایور باید `ITerminalDriver` را پیاده‌سازی کند و DLL آن داخل پوشه `drivers` کنار برنامه قرار گیرد. مقدار `Code` باید با `driver_code` دستگاه در POS برابر باشد. درایور نباید PIN یا داده حساس کارت را بخواند یا ذخیره کند. اگر پاسخ پس از ارسال فرمان مبهم شد، نتیجه باید `unknown` باشد و پرداخت خودکار تکرار نشود.

## امنیت
- فقط HTTPS با اعتبارسنجی گواهی سیستم پذیرفته می‌شود.
- توکن در header اختصاصی ارسال می‌شود و log نمی‌شود.
- POS فقط IPهای شبکه خصوصی را برای کارتخوان می‌پذیرد.
- فقط افزونه‌های درایور مورد اعتماد نصب شوند.
