# گزارش تطبیق سورس 3Food POS

تاریخ بررسی: 2026-11-17

## ورودی‌های بررسی‌شده

- آرشیو اصلی `grok-workspace.zip`: 317 ورودی ZIP، 5,233,182 بایت داده بازشده، 245 فایل عادی پس از استخراج.
- آرشیو مهاجرت `3food-pos-php-migration.zip`: 144 ورودی ZIP، 1,289,438 بایت داده بازشده، 115 فایل عادی پس از استخراج.
- آرشیو `3food-pos-php-final-source.zip` با اندازه 58,598 بایت عمداً مبنای کار قرار نگرفت؛ طبق بررسی قبلی ناقص است.

## یافته‌های تطبیق

- همه مسیرهای مشترک میان دو آرشیو از نظر SHA-256 یکسان بودند؛ یعنی نسخه مهاجرت فایل‌های هم‌نام را تغییر نداده و فایل‌های جدید PHP/MySQL را اضافه کرده است.
- آرشیو مهاجرت 130 فایل کمتر از سورس اصلی دارد. بخش مهمی از موارد حذف‌شده شامل پوشه‌های محیط Grok و خروجی Vercel است؛ این‌ها به‌تنهایی به معنی حذف قابلیت‌های برنامه نیستند، اما حذف باید با بررسی وابستگی‌ها و مسیر build انجام شود.
- فایل‌های افزوده‌شده در مهاجرت شامل API PHP، schema MySQL، نمونه تنظیمات خصوصی و مستندات فارسی هستند.

## وضعیت فنی قابل اثبات

- `php-backend/public/api/index.php` و `php-backend/private/config.example.php` از نظر نحو PHP با `php -l` بدون خطا بررسی شدند.
- محیط فعلی فقط افزونه‌های `PDO` و `openssl` را در خروجی PHP نشان داد؛ وجود `pdo_mysql` در محیط آزمون فعلی تأیید نشد.
- گزارش وضعیت مهاجرت صراحتاً اعلام می‌کند اتصال UI React به API، انتقال منبع داده از localStorage به MySQL، محاسبات مالی کامل سمت سرور، موجودی، SMS امن، backup/restore، تست چنددستگاهی، build استاتیک و آزمون واقعی MySQL هنوز کامل نیستند.
- `package.json` همچنان اسکریپت build فعلی را به اجرای `db:migrate` از طریق Node متصل می‌کند؛ بنابراین build PHP-only مستقل هنوز اثبات نشده است.

## تصمیم ایمنی

این شاخه برای ادامه توسعه و بازبینی است. تا تکمیل اتصال UI/API و آزمون end-to-end روی staging با MySQL واقعی، روی `pos.3food.ir` deploy نشود. آرشیو اصلی باید به‌صورت مستقل و بدون تغییر نگهداری شود.
