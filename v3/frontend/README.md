# PersiaCoder POS V3 — Frontend workspace

این پوشه workspace مستقل رابط کاربری نسخه تجاری V3 است.

## مرز استقلال

- این frontend به runtime موجود V2 در ریشه مخزن وابسته نیست.
- هیچ فایل یا ماژولی از root `src/`، store قدیمی، API client قدیمی یا runtime V2 import نمی‌شود.
- احراز هویت، انتخاب کسب‌وکار/شعبه، کاتالوگ، سفارش، مرکز سفارش، آشپزخانه و بخش‌هایی از انبار به API واقعی V3 متصل شده‌اند؛ سطح اتصال هر ماژول را از کد و ROADMAP بررسی کنید.
- بخش مالی/صندوق در بسته FIN-01 به API واقعی تعریف صندوق، بازکردن شیفت، بستن شیفت و بررسی اختلاف متصل شده است؛ ثبت گردش دستی، هزینه‌ها، پرداخت‌ها و گزارش‌های مالی هنوز کامل نیست.
- فروشگاه آنلاین فعلاً prototype مستقل با داده نمونه است و هنوز ثبت سفارش storefront یا اتصال checkout به API واقعی ندارد.
- پنل پیامک در این نسخه هنوز پیاده‌سازی نشده است. برخی صفحات و نماها ممکن است همچنان prototype باشند؛ وجود UI به معنی قابلیت عملیاتی نیست.
- تا عبور از تست‌های پایان فاز و پذیرش staging، workspace برای انتشار روی هاست مشتری آماده محسوب نمی‌شود.

## ساختار UI

- توکن‌های طراحی: `src/tokens.css`
- اجزای مشترک: `src/shared/ui/` (primitiveها، کنترل‌های فرم و جدول typed)
- مستند طراحی و قرارداد componentها: [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md)

## اجرای محلی

نیازمند Node.js سازگار با Vite 8 و npm است.

```powershell
cd v3/frontend
npm install
npm run dev
```

## بررسی و build

```powershell
npm run typecheck
npm run build
```

در حال حاضر lockfile تولید نشده است؛ پس از اجرای `npm install` در محیط توسعه، فایل lock باید commit شود. تست واحد، lint، build و پذیرش مرورگر هنوز اجرا نشده‌اند. هیچ تست یا build موفقی صرفاً با ایجاد این فایل‌ها ادعا نمی‌شود.
