# PersiaCoder POS V3

مخزن مستقل محصول تجاری PersiaCoder POS V3.

این مخزن مرجع اصلی توسعه نسخه سوم است. کدهای اختصاصی V3، Backend، Frontend، دیتابیس و مهاجرت‌ها، اسناد معماری و محصول، اسکریپت‌های اعتبارسنجی و Workflowهای CI در این مخزن نگهداری می‌شوند. اجزای V2 و مهاجرت PHP/MySQL نسخه قبلی عمداً وارد این مخزن نشده‌اند.

## وضعیت انتقال اولیه

- انتقال ساختار اختصاصی V3 از مخزن کاری قبلی انجام شد.
- 170 فایل منتخب V3 در شاخه `main` کپی شدند و مسیرهای اصلی حفظ شده‌اند.
- منبع انتقال: `jalilsh7/3Food-pos`، شاخه `feature/3food-pos-next-release-v2`، commit `4e82753cfe95f2824d75fbbcda738d74e3bf9f64`.
- انتقال به‌صورت کپی محتوای فایل‌ها و ایجاد تاریخچه commit جدید در این مخزن انجام شده است؛ تاریخچه commitهای مخزن مبدأ به‌صورت کامل بازنویسی/منتقل نشده است.
- انتقال فایل‌ها به معنی موفقیت Build، تست یا استقرار نیست؛ این موارد باید در همین مخزن مستقل اجرا و تأیید شوند.

## ساختار اصلی

- `v3/backend/` — هسته PHP و API نسخه سوم
- `v3/frontend/` — رابط React/Vite نسخه سوم
- `database/v3/` — Schema، migration و ابزارهای دیتابیس
- `scripts/` — تست‌ها و اسکریپت‌های اعتبارسنجی اختصاصی V3
- `.github/workflows/` — گردش‌کارهای CI نسخه سوم
- اسناد معماری، دامنه محصول، UX و نقشه راه در ریشه مخزن
